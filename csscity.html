🎨 CSS Lesson

What is CSS?

CSS means Cascading Style Sheets. CSS is used to design webpages with colors, fonts, backgrounds and layouts.

🎨 Colors

CSS colors help us change text and background appearance. 

h1 {
 color: blue;
}

body {
 background-color: lightblue;
}

🔤 Fonts

CSS fonts change the style and size of text. 

h1 {
 font-family: Arial;
 font-size: 40px;
}

🧱 Borders & Spacing

Borders make elements attractive. Padding and margin create space. 

.box {

border: 2px solid black;

padding: 20px;

margin: 10px;

}
